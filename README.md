## 📌 Overview

SmartPantry AI is an intelligent pantry management system that recommends recipes based on available ingredients.

The system uses Python, Pandas and TF-IDF to analyse ingredients and recommend meals based on what users already have in their pantry.

It also supports nutrition-aware meal planning and personalised recommendations.

---

## 🚀 Features

- Pantry Management
- Recipe Recommendation
- Nutrition-aware Suggestions
- Goal-based Meal Planning
- Ingredient Similarity using TF-IDF

---

## 🛠 Technologies

- Python
- Pandas
- NumPy
- TF-IDF
- Kaggle Food.com Dataset
